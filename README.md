# AI Career Upgrade

A lightweight, dependency-free static web app for professionals who want a focused path into practical AI roles. The page includes:

- A hero section with a readiness score.
- Interactive role-track cards for AI product builders, AI data analysts, and AI operations strategists.
- A 12-week execution roadmap.
- A clickable progress checklist with a downloadable text summary.

## Run locally

```bash
npm start
```

Then open <http://localhost:5173>.

## Build

```bash
npm run build
```

The build command copies the static assets into `dist/`.
