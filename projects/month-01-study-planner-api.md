# Month 01 Project — Study Planner API

## PRD

Build an API that can store planner days, completion status, study notes, and monthly project progress.

## Architecture

1. React dashboard renders JSON planner content.
2. API layer will later persist completion and notes.
3. PostgreSQL stores users, planner days, resources, and notes.

## Tech Stack

- TypeScript
- React + Vite
- Node.js API layer
- PostgreSQL
